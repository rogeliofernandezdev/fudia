# Referencias visuales de comanda

Capturas históricas usadas para comparar la evolución responsive de Salón/Comanda.
No son assets de producción y no deben importarse desde la aplicación.

Las capturas nuevas deben conservarse aquí con nombres descriptivos; no usar archivos
`__*.png` en la raíz del proyecto.

## Referencia indicada por el usuario

[Food Delivery App UIUX Design · Food Ordering App UI](https://www.behance.net/gallery/246669901/Food-Delivery-App-UIUX-Design-Food-Ordering-App-UI)
se toma como referencia para la comanda y sus iconos, conservando la identidad
de FudIA y sin copiar marcas ni piezas publicitarias.

La captura compartida por el usuario permite observar un CTA con extremos
completamente redondeados, iconos lineales simples, fotografías de producto y
jerarquía compacta. Se adapta ese radio tipo píldora a «Ver comanda» y se usa
una bolsa de pedido de nuestra familia SVG, manteniendo el índigo de FudIA
en lugar del naranja de la referencia. No se copia una biblioteca de iconos
ni se afirma haber identificado la utilizada por el proyecto.
