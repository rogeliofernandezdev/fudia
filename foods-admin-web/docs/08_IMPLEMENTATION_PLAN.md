# Plan de implementación

## Base disponible

- Acceso administrativo responsive y estados de envío.
- Shell con navegación agrupada, contexto de local y búsqueda de opciones autorizadas.
- Dashboard analítico por periodo (Hoy / 7 / 30 días) con comparación, tendencia, desgloses por canal, medio de pago y categoría, productos destacados y operación en vivo.
- Vistas consistentes para menú, inventario, compras, ventas y configuración.
- Sistema visual único para botones, campos, filtros, tablas y estados.
- Configuración monetaria y fiscal conectada, responsive y con vista previa.
- CRUD conectado de categorías y productos: búsqueda, paginación, creación,
  edición, reactivación y desactivación segura.
- Disponibilidad diaria por local: búsqueda del menú, cupo operativo y cambio
  rápido entre disponible, pocas unidades y agotado sin editar la ficha.
- Menús y combos compuestos: wizard dedicado, grupos configurables, plantilla de
  menú del día, alternativas basadas en productos existentes y disponibilidad
  automática según los mínimos de cada grupo obligatorio.
- Plantilla de gestión homologada en Ventas, Comprobantes, Inventario, Compras,
  Clientes y Locales, con filtros, estados, acciones iconográficas, tabla de
  escritorio, tarjetas móviles y paginación uniforme.

## Próximas verticales

Conectar dashboard y productos al cliente OpenAPI; completar edición de recetas;
movimientos y conteos; órdenes y recepciones; comprobantes, usuarios, permisos,
locales e integraciones. Cada vertical debe incluir carga, error, vacío y permisos.
